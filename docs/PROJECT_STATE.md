# CurlStreamer project state

Updated September 9, 2026. This page supersedes historical progress notes.

## Direction

Finish a usable hobby release before long rink testing. Keep Vercel for the website; package Windows Studio as one installer with the managed recording/streaming runtime. Phones use browser invitations. See the [release plan](hobby-release-plan.md).

## Completed foundation

- Direct-network cameras and two-camera composition with full portrait/sponsor frames.
- Scoring and append-only Undo.
- Independent MKV recording and guarded native streaming output.
- Desktop pairing, once-only target delivery, lease expiry and quarantine.
- Independent YouTube channel/stream/broadcast observations and owned retirement.
- Native camera address visibility scoped to the exact local renderer origin.
- Short real unlisted YouTube rehearsal with both cameras and sponsor visible.

The [rehearsal record](m4-controlled-rehearsal.md) distinguishes successful evidence from unverified checks. Private snapshots, recordings and logs remain outside Git. Historical milestones are not substitutes for current build results.

## Remaining product work

1. Source consolidation is complete in draft PR #65 with hosted checks.
2. M5 launch window and relocatable package are implemented and locally checked; private installer build/lifecycle checks are implemented; distribution notices, visual review and clean-machine checks remain.
3. Integrate the ordinary game workflow without developer commands.
4. Verify Vercel configuration and stable-origin sign-in/pairing.
5. Package a hobby beta with clear errors, recovery, version information and updates.

Audio, long endurance, adverse-network drills and rink acceptance remain later work. They do not block software development. Authorization, recording preservation and reliable provider cleanup remain essential.

## Operational boundary

The rehearsal broadcast ended, resources were retired and the test sponsor was disabled. The activated local app was shut down and the operator returned to default-deny. Source consolidation does not activate production. Website builds do not automatically apply database migrations.
