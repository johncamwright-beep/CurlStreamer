# Microphone sync

In a game's Camera Settings, **Microphone sync adjustment** supports −5 to +5 seconds. The value is saved with that game.

- If the external USB/DJI microphone sounds before the action, choose a positive value to delay it.
- If it sounds after the action, choose a negative value. Studio holds the camera picture and camera sound together while leaving the external microphone undelayed.
- Zero adds no correction.

For example, if the microphone is about two seconds late, start with **−2 seconds**. Check a visible clap in the outgoing video and adjust in smaller steps. Changing a negative setting briefly rebuilds the camera buffer.

This changes the broadcast output. Headphones plugged directly into the receiver are unaffected.
