# Sponsor display

JPEG, PNG, and WebP files up to 12 MB are accepted in mock mode, decoded in-browser, scaled to fit 1600×900, re-encoded, and kept in process memory. PNG transparency is retained. Individual failures do not discard successful selections. The configurable production limits should reflect organization quota, egress memory, and bandwidth rather than an arbitrary image count.

Enabled images follow the displayed order. The server stamps mode start/navigation time, allowing every polling view to derive the same index. The default is a four-second full-screen break and privacy mute; overlay uses the sponsor side rail. Pause, previous, next, disable, rotate, reorder, and remove do not crop assets. A production scheduler must enforce the 30-minute scorer-disconnect safety timeout and persist sessions/audit events.
